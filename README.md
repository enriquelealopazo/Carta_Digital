# Carta_Digital · Arica

Cartas digitales con pedido directo a WhatsApp para negocios de Arica.

- `index.html` — Demo Premium (horario automático, agotados, ubicación, Instagram/reseñas, edición por Google Sheet, contador de visitas)
- `pro.html` — Demo Pro (carta + carrito + pedido por WhatsApp)
- `plantilla-carta.csv` — plantilla para la Google Sheet que edita el dueño
- `tarjeta-mesa-QR.pdf` — tarjetas de mesa imprimibles

Para adaptar a un cliente: editar solo el bloque `CONFIGURACIÓN DEL NEGOCIO` dentro de cada HTML.
